TASK 1 — Guideline 4.8: Add Sign in with Apple (REQUIRED)
Apple mandates that any app offering a third-party login (Google Sign-In)
must also offer Sign in with Apple as an equivalent option. This is the
primary rejection reason.

What to build:
- Add Sign in with Apple button to LoginView in App/CodeRedApp.swift
  (alongside the existing Google button and "Member sign-in" disclosure)
- Implement signInWithApple() in AuthenticationService (same file, ~line 255)
  using ASAuthorizationAppleIDProvider + Firebase OAuthCredential
- Add Sign in with Apple capability/entitlement to the Xcode project

Implementation notes:
- AuthenticationService is a class ObservableObject in App/CodeRedApp.swift
- It already has: signInWithGoogle(), signInWithEmail(), signOut()
- It already has: @Published var isLoggedIn, @Published var signInError
- On successful SIWA, Firebase's addStateDidChangeListener fires automatically
  and sets isLoggedIn = true — same flow as Google and email auth
- Requires: import AuthenticationServices, import CryptoKit
- Requires: private var currentNonce: String? stored on AuthenticationService

Standard Sign in with Apple + Firebase pattern:
  1. Generate a random nonce string (CryptoKit)
  2. SHA256-hash it
  3. Create ASAuthorizationAppleIDProvider().createRequest()
     set requestedScopes = [.fullName, .email], set nonce = sha256Nonce
  4. Present via ASAuthorizationController
  5. In ASAuthorizationControllerDelegate.didCompleteWithAuthorization:
     - Extract appleIDToken from credential.identityToken
     - Build OAuthProvider.credential(providerID: .apple, idToken: token, rawNonce: currentNonce)
     - Call Auth.auth().signIn(with: credential)
  6. AuthenticationService must conform to:
     ASAuthorizationControllerDelegate
     ASAuthorizationControllerPresentationContextProviding

Adding capability to Xcode project (project.pbxproj):
- Check if a .entitlements file already exists; if not, create
  CodeRed/CodeRed.entitlements with:
    <?xml version="1.0" encoding="UTF-8"?>
    <!DOCTYPE plist PUBLIC "-//Apple//DTD PLIST 1.0//EN" ...>
    <plist version="1.0"><dict>
      <key>com.apple.developer.applesignin</key>
      <array><string>Default</string></array>
    </dict></plist>
- Add CODE_SIGN_ENTITLEMENTS = CodeRed/CodeRed.entitlements to both
  Debug and Release configs in project.pbxproj
- Add PBXFileReference + PBXBuildFile entries for the entitlements file
  (it goes in Resources build phase, not Sources)
